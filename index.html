📘 آموزش ۱ — فونت چیست؟

در این سایت بیشتر استایل‌ها با کاراکترهای Unicode ساخته می‌شوند. یعنی متن معمولی را به کاراکترهای خاص تبدیل می‌کنیم تا ظاهر متفاوتی پیدا کند.

📘 آموزش ۲ — ساخت فونت ساده

برای ساخت یک فونت، می‌توانیم برای هر حرف یک کاراکتر جایگزین تعریف کنیم.

const font = { A: "𝔄", B: "𝔅", C: "ℭ" }; function makeFont(text){ return [...text] .map(x => font[x] || x) .join(""); }

📘 آموزش ۳ — فونت + ایموجی

بعد از تبدیل متن می‌توانیم ایموجی را به ابتدا و انتهای متن اضافه کنیم.

const result = "🔥 " + makeFont(text) + " 🔥";

📘 آموزش ۴ — ساخت قاب

قاب‌ها با قرار دادن نماد قبل و بعد از متن ساخته می‌شوند.

const result = "꧁" + text + "꧂";

📘 آموزش ۵ — ساخت فونت ترکیبی

می‌توانیم چند قابلیت را پشت سر هم اجرا کنیم: فونت + قاب + ایموجی + افکت.

꧁❤️ + FONT + ❤️꧂
